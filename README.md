# Event Management System

This project is an Event Management System (EMS) built with a NextJS frontend using Material UI and a NestJS backend using TypeORM with PostgreSQL. It allows users to create, view, update, and delete events. Additionally, it provides a simple recommendation mechanism and an optional Google Maps view for visualizing events.

## Projects Structure

- **backend/** – Contains the NestJS RESTful API with endpoints for CRUD operations and event recommendations.
- **frontend/** – Contains the NextJS application with pages for event listing, details, creation, editing, and an optional map view.
- **README.md** – Contains project overview and setup instructions.
